# J4 UPSC Command Centre

A local-first UPSC CSE 2028 preparation dashboard.

## Included

- Prelims, Mains, CSAT and Sociology syllabus tracker
- Daily three-priority planner and focus timer
- Study-session logging and weekly consistency chart
- Spaced-repetition revision queue
- Mock-test score and accuracy analysis
- Private PDF/TXT/Markdown study-material library with randomized tests
- Generated-test accuracy, subject breakdowns and answer review
- Mains answer-writing log and self-review checklist

Progress is stored in the browser using `localStorage`; study-material text is stored in IndexedDB. No account or external database is required for this version.
