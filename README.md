# J4 UPSC Command Centre

A local-first UPSC CSE, APSC CCE and SSC CHSL preparation dashboard.

## Included

- Separate UPSC, APSC and SSC CHSL syllabus views with independent topic ticks
- APSC Prelims, aptitude, Mains and Assam GS V checklist
- CHSL Tier I, Tier II, computer knowledge and typing/skill checklist
- Overall and subject-wise progress charts for the selected exam
- Daily three-priority planner and focus timer
- Study-session logging and weekly consistency chart
- Spaced-repetition revision queue
- Mock-test score and accuracy analysis
- Dedicated 15-minute CHSL speed-drill timer
- Private PDF/TXT/Markdown study-material library with randomized tests
- Generated-test accuracy, subject breakdowns and answer review
- Mains answer-writing log and self-review checklist

Progress is stored in the browser using `localStorage`; study-material text is stored in IndexedDB. No account or external database is required for this version.

Open **Syllabus** and choose **UPSC**, **APSC** or **SSC CHSL**. Each exam has its own stage filters and progress. The selected exam is remembered, and existing UPSC topic IDs are preserved. These grouped checklists are study aids; the linked official exam sources provide detailed syllabus coverage. The CHSL reference is the verified 2025 SSC notice.
